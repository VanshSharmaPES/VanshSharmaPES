## Hey, I'm Vansh

B.Tech CSE (AI/ML) at PES University, Bengaluru. I build full-stack systems where the ML layer has to actually earn its place, not just exist.

Two projects that reflect how I think about this:

**ClearTriage** — a hospital triage system that lets nurses ask "why?" after every AI prediction and get a plain-English explanation via SHAP. The point wasn't the model; it was making the model's reasoning auditable by people under pressure.

**Sanjeevani** — reads handwritten prescriptions and delivers the instructions aloud in multiple languages. Built for patients where the failure mode is taking the wrong dose.
